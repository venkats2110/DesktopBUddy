# DesktopBuddy (Deskbot)

A DIY desktop companion robot: a boxy wheeled bot with a screen face, arms, and sleep / active / recharge modes.

## Hardware

| Part | Model |
|---|---|
| MCU | 7Semi ESP32-S3-WROOM-1U-N16R8 (16 MB flash, 8 MB octal PSRAM) |
| Display | DFRobot DFR0664 2.0" 320x240 ST7789 (SPI) |

### Display pin map

| Signal | GPIO |
|---|---|
| SCLK | 12 |
| MOSI | 11 |
| CS | 10 |
| DC | 17 |
| RST | 18 |
| Backlight (PWM) | 16 |

### Rules

- Never enable Wi-Fi or Bluetooth (the -1U module has no antenna fitted).
- Never use GPIO 35/36/37 (used by the octal PSRAM).

## Build and upload

1. Open this folder in VS Code with the PlatformIO extension.
2. Check `upload_port` / `monitor_port` in `platformio.ini` match your machine.
3. Run **PlatformIO: Upload**, then **Monitor** (115200 baud).

## Project layout

| Path | What it is |
|---|---|
| `include/faces.h` | All expressions. **Generated by the [Face Lab](https://claude.ai/artifact/H5K6h3mLH5sha77ZCGoKEy), don't edit by hand.** |
| `src/display_config.h` | Display driver settings and pin map |
| `src/face_engine.h/.cpp` | Draws and animates faces: tweening, blinking, glances, breathing, extras (blush, Zzz, tears, hearts...) |
| `src/main.cpp` | Cycles through every face; serial commands for testing |

## Updating the faces

1. Open the Face Lab, tweak expressions, then **Export → faces.h (all) → Copy**.
2. Paste over the whole of `include/faces.h`.
3. Upload. The firmware picks up new, renamed or removed faces automatically.

## Serial commands (115200 baud)

| Type | Does |
|---|---|
| a face name, e.g. `grumpy` | Holds that face |
| `auto` | Goes back to cycling through every face (2.5 s each) |
| `list` | Prints all face names |

### Display troubleshooting

- **Colours wrong/inverted:** flip `cfg.invert` in the panel config.
- **Red and blue swapped:** flip `cfg.rgb_order`.
- **Noise or garbage on screen:** lower `SPI_FREQ` (breadboard wiring rarely handles 40 MHz).
- **Screen turns solid red at start-up:** the frame buffer couldn't be allocated in PSRAM, so check the PSRAM build flags.
- **Face upside down:** change `tft.setRotation(1)` to `3` in `src/main.cpp`.
